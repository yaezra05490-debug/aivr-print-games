# משחקים להדפסה - AiVR מערכות ואוטומציה

תוכנה חינמית בעברית למחשב (Windows), שמייצרת, פותרת ומדפיסה:

- **סודוקו** – 4 רמות קושי, כל לוח עם פתרון יחיד. משחק על המסך, רמז, בדיקה ופתרון. הדפסה של 4 לוחות בדף A4, עם דפי פתרונות.
- **שחור ופתור (נונוגרם)** – מאגר מובנה של כ-2,700 ציורים ב-36 נושאים (חגים, שבת, בית הכנסת, ירושלים ועוד), בגדלים 10 עד 30. כל חידה נפתרת בהיגיון. אפשר גם לצייר חידה בעצמכם או לייבא תמונה.
- **תפזורת** – מקלידים רשימת מילים ומקבלים תפזורת ב-3 רמות, בכל 8 הכיוונים, עם דף פתרון.

ייצוא ל-PDF מוכן להדפסה, בכמויות – מעולה למורים, לגננות, להורים ולחוברות לשבת ולחגים.

## הורדה

**[להורדת הגרסה האחרונה (קובץ zip)](https://github.com/yaezra05490-debug/aivr-print-games/releases/latest/download/AiVR-Games-5.2.zip)**

1. מחלצים את קובץ ה-zip לתיקייה.
2. מפעילים את `AiVR-Games.exe`. אין צורך בהתקנה.
3. אם Windows מציג "Windows הגן על המחשב שלך" – לוחצים "מידע נוסף" ואז "הפעל בכל זאת" (זה קורה לכל תוכנה חדשה שאינה חתומה).

דרישות: Windows 10 או 11 (‏.NET Framework 4.8, מותקן כבר ברוב המחשבים). ל-PDF נדרש Edge או Chrome.
